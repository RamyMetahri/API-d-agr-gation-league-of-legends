# Riot Stats — Front

Interface React + Vite du projet. La présentation complète, l'architecture et les instructions sont dans le [README principal](../README.md).

```bash
npm install
npm run dev       # http://localhost:5173
npm run lint
npm run build
```

La variable `VITE_API_URL` indique l'URL de l'API (voir `.env.example`). Par défaut, c'est `http://127.0.0.1:8000`.
